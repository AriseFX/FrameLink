# ScreenCast Send 2.4.3

启动 `ScreenCastSendCpp.exe`，请保留旁边的 `Processing.NDI.Lib.x64.dll`。两台电脑连接同一局域网，在 Windows 防火墙中允许本程序在专用网络通信。接收软件选择 `电脑名 (源名称)`。

选定显示器和中心 320×320、416×416、640×640，或填写自定义 X/Y/宽高。设置帧率（支持 240 fps）、DXGI 或自动采集、NV12，然后点击“开始发送”。发送期间修改采集设置需要先停止。NV12 宽高需为偶数。

点击右上角关闭按钮或按 Alt+F4，窗口收起到系统托盘，发送继续运行。双击托盘图标恢复；右键托盘图标可停止发送或选择“退出”彻底关闭程序。没有开始发送时收起到托盘不会自动开始发送。

关闭预览可减少发送端工作。收起到托盘自动暂停预览生成，恢复时按预览复选框状态恢复。精确调度默认关闭，可选开启以改善固定帧率定时，但不保证降低全链路延迟。

游戏切换全屏或显示模式导致 DXGI 暂时失效时，程序会自动重建采集。自动模式固定帧率下可先回退 GDI，每秒尝试恢复 DXGI；底部会显示当前状态。强制 DXGI 与无上限模式等待恢复期间可能暂时没有新画面。恢复无需重新点开始发送；如果采集区域已超出改变后的桌面范围，则需要重新选择区域。游戏无边框窗口模式通常可减少模式切换造成的中断。

右侧耗时为发送端采集、转换、异步提交调用平均耗时，不是网络、解码或全链路延迟。本程序不发送音频，支持 SDR 8 位画面；Full NDI 不能保证逐像素数学无损。DXGI 区域应位于单个非旋转显示器内。设置保存在 `%LOCALAPPDATA%\ScreenCastSendCpp\settings.ini`。

缺少运行库时安装 Microsoft Visual C++ 2015–2022 x64 Redistributable。
